## ?? JWT Token Structure

```
???????????????????????????????????????????????????????????????????????
?                       JWT TOKEN STRUCTURE                           ?
???????????????????????????????????????????????????????????????????????

Header:
{
  "alg": "HS256",
  "typ": "JWT"
}

Payload (Claims):
{
  "sub": "802f9698-b3df-4d60-9982-bfbb205aac4c",    ? User ID
  "email": "user@ironlogic.ai",                     ? Email
  "jti": "12345678-90ab-cdef-1234-567890abcdef",   ? Token ID
  "role": "User",                                   ? ? ROLE CLAIM
  "nbf": 1749999999,                                ? Not Before
  "exp": 1750086399,                                ? Expiration (UTC)
  "iss": "IronLogicAPI",                            ? Issuer
  "aud": "IronLogicClient"                          ? Audience
}

Signature:
HMACSHA256(
  base64UrlEncode(header) + "." +
  base64UrlEncode(payload),
  secret_key_from_configuration
)
```

?????????????????????????????????????????????????????????????????

? user-guid-2             ? athlete@ironlogic.ai ? athlete@...  ?
?????????????????????????????????????????????????????????????????

AspNetUserRoles:
?????????????????????????????????????????????????????
? UserId                  ? RoleId                  ?
?????????????????????????????????????????????????????
? user-guid-1             ? role-guid-1 (Admin)     ?  ? Admin user
? user-guid-2             ? role-guid-2 (User)      ?  ? Regular user
?????????????????????????????????????????????????????

Query to get user's role:
SELECT r.Name 
FROM AspNetRoles r
INNER JOIN AspNetUserRoles ur ON r.Id = ur.RoleId
WHERE ur.UserId = 'user-guid-1'
? Result: "Admin"

? UserManager.GetRolesAsync() handles this automatically
